# Excluded from the manuscript

Native Montoya/FRVCP nonlinear charging output is **invalid_external_sensitivity**.
Records include `feasible=true`, `reason=optimal`, and non-finite durations.
Do not treat this as completed scientific sensitivity analysis.
The original bytes are preserved as `final_montoya_nonlinear.jsonl.rawdebug`.
The sanitized copy serializes non-finite numbers as null and sets `duration_nonfinite=true`.
