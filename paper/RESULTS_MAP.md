# Results map → `results_paper/`

All publication figures (PDF + PNG) and tables are generated by:

```bash
python scripts/paper/record_illustrative_val_episode.py   # once (VAL case study JSON)
python scripts/paper/build_results_paper.py
python scripts/paper/build_results_paper.py --verify
```

`scripts/paper/build_paper_artifacts.py` is deprecated and delegates to the official builder.
