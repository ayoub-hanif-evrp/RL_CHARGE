Route-generation pipeline used to build the frozen customer sequences. SynthCharge draws a source instance. PyVRP then solves a customer-only capacitated pickup vehicle-routing problem with time windows and does not decide battery charging. Each ordered vehicle route is submitted to a whole-route charging-certificate search, which looks for one feasible charging trajectory and is not a globally exact charging optimizer. Routes are classified by charging requirement and retained only while layout, frozen-route-length, and charging-requirement quotas remain open. The retained sequences are frozen. FA-HPPO later chooses charging insertions and charge amounts on those sequences; it does not create or reorder customers. A compact horizontal version with the unverified-search and quota-rejection branches is given in figure_route_generation_pipeline_horizontal.
